# Práctica Parcial 1 · Sistemas Digitales I (MCF5272)

App web de un solo archivo para practicar el Parcial 1 de Sistemas Digitales I (ETSIT UPM),
basada en el microcontrolador ColdFire MCF5272.

- **`practica_parcial.html`** — la app. Ábrela directamente en el navegador, sin instalar nada.
- **`generador_ejercicios_parcial1_SDG1.md`** — especificación de los tipos de ejercicio que genera y corrige.
